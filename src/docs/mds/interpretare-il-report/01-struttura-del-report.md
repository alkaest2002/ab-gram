Il report prodotto da AB-Grid è organizzato in sezioni che vanno lette in
ordine: prima il quadro generale, poi i dettagli.

## Le sezioni del report

Il report si compone di quattro blocchi:

1. Riepilogo del gruppo.
2. Metriche di gruppo.
3. Metriche individuali.
4. Grafici.

### Riepilogo del gruppo

La prima pagina riassume i dati di base:

```json
{
  "membri": 5,
  "preferenze": 7,
  "rifiuti": 2
}
```

## Come leggere il report

Parti dal riepilogo per capire la dimensione del gruppo, poi scendi nelle
metriche e nei grafici per i dettagli.
